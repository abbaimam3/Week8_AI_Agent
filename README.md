# Week 8 Assignment: AI Agents

This directory contains the submission for the "AI Agents" assignment.

## Directory Structure

*   **Part 1: Short Answer Questions**
    *   `Part1_Short_Answers.md`: Answers to Q1-Q5 (LangChain vs AutoGen, Supply Chain, Ethics, etc.).
*   **Part 2: Case Study Analysis**
    *   `Part2_Case_Study_Analysis.md`: Strategy for "AutoParts Inc." (3 Agent Types, ROI, Risks).
*   **Part 2: Simulation**
    *   `Part2_Simulation_Design.md`: Design document for the n8n Predictive Maintenance workflow.
    *   `n8n_workflow_simulation.json`: The actual JSON workflow file to import into n8n.

## How to Run the Simulation
1.  Open [n8n](https://n8n.io/).
2.  Create a new workflow.
3.  Import the `n8n_workflow_simulation.json` file.
4.  Configure your credentials (OpenAI, Slack, Jira).
5.  Execute the workflow to see the agent in action.
